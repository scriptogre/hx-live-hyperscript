# hx-live-hyperscript

Hyperscript-flavored shorthand syntax for the htmx `hx-live` extension.

This repository contains the extension source, its browser tests, and the
draft documentation migrated from the htmx 4 development branch.

The extension requires `hx-live`. It rewrites shorthand expressions to the
core `q()` API before they run.

See [`docs/hx-live-hyperscript.md`](docs/hx-live-hyperscript.md) for the syntax.
